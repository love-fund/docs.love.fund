## Community

The conversation happens in the [love.fund Telegram](https://t.me/+m3faFlCfyvcyMDdh).

You can also join the discussion on the [Gitcoin governance forum](https://gov.gitcoin.co/).

If you're interested in Techne, fill out the [Techne interest form](https://forms.gle/gh7vNtZJhpCBBRJD9).

## Improve these docs

These are love.fund's working docs, and they're open source ([CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)); by opening a PR you agree to license your contribution the same way. If you spot something wrong, have an idea, or want to sharpen a page, open a pull request on [GitHub](https://github.com/love-fund/docs.love.fund).

Every page is a Markdown file in `src/content/docs/`, so most changes are a quick edit. Small, focused PRs are easiest to review. If you're not sure where to start, open an issue or bring it to the Telegram.
