## Single Pager (`/reference/single-pager/`)

The Single Pager shows every docs page end to end, in sidebar order. It must always reflect the whole site. Keep it in sync on every docs change, without being asked.

How it stays in sync:

- `src/pages/reference/single-pager.astro` builds the page from `src/content/docs/` by walking the sidebar in `src/sidebar.mjs`. The same file feeds the site navigation through `astro.config.mjs`.
- Edits to an existing page show up automatically. Don't copy content into the Single Pager by hand.
- **When you add, rename, move or delete a page, update `src/sidebar.mjs` in the same change.** A page that isn't in the sidebar isn't in the Single Pager. Pages in `roadmap/` and `reference/` are autogenerated, so they only need the right `sidebar.order` in frontmatter. `start-here/` and `ontology/` are listed by hand.
- Content that isn't a docs page doesn't appear on the Single Pager: anything in `src/pages/`, components such as the header strip or footer, or a sidebar entry that's a plain `link`. If you add important information in one of those places, also add it to a docs page.

After any docs change, load `/reference/single-pager/` on the dev server. Check that it returns 200 and that the changed page appears in the right place.
